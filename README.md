# Novarub Landing Page

Este proyecto es una **landing page** desarrollada con [Astro](https://astro.build/) para una empresa local de mi pueblo llamada **Novarub**. Aunque el negocio no prosperó, el proyecto fue una excelente oportunidad para aprender y experimentar con desarrollo web moderno.

---

## Concepto de Landing Page

Una **landing page** es una página web diseñada principalmente para promocionar un producto, servicio o negocio, con el objetivo de **captar la atención del visitante y generar interacción** (por ejemplo, descargar un catálogo o contactar a la empresa).
En este proyecto, la landing page muestra los productos y servicios de Novarub, además de permitir el contacto con el equipo técnico.

---

## Tecnologías utilizadas

* **[Astro](https://astro.build/)** – Framework principal para la construcción de la página.
* **Tailwind CSS** – Para estilos rápidos y responsivos.
* **React** – Para algunos componentes dinámicos (integrado con Astro).

## Clonar el repositorio

```bash
git clone https://github.com/tu-usuario/novarub-landing.git
cd novarub-landing
```

---

## Instalar dependencias

```bash
npm install
# o si usas Yarn
# yarn
```

---

## Correr el proyecto en desarrollo

```bash
npm run dev
# o con Yarn
# yarn dev
```

Luego abre tu navegador en `http://localhost:4321` para ver la landing page.

---

## Construir para producción

```bash
npm run build
# o con Yarn
# yarn build
```

Esto generará los archivos estáticos listos para subir a un hosting.
